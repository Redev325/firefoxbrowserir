Unofficial Firefox-based browser project

Browse the web your way.

A customized Firefox-based browser project built from the Iceraven/Fenix codebase, with an Android version now and a desktop Firefox-based version planned alongside it.

Get Android builds View source

Android

The current fork uses Iceraven/Fenix and GeckoView for real web browsing on Android devices.

Desktop

A separate Firefox desktop source tree will be used for Windows, macOS, and Linux builds.

Open source

Source, build configuration, and future releases are published through the GitHub repository.

This project is independent and is not an official Mozilla Firefox product. GitHub Pages hosts this website; the actual browser remains a native application.
